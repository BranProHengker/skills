## 🚀 Quick Install

### Install All Skills Globally
Install the entire skill package to all supported coding agents on your machine:

```bash
npx skills add BranProHengker/skills --all -g
```

### Install a Specific Skill
```bash
# Install only the Anti-Slop craft standard
npx skills add BranProHengker/skills --skill no-slop-anymore -g

# Install only the Agent behavioral guidelines
npx skills add BranProHengker/skills --skill antigravity-guidelines -g
```
